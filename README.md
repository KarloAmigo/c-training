# C-Training 🧑‍💻

Meine Übungsaufgaben in **C**, die ich parallel zu [CS50x](https://cs50.harvard.edu/x/) (Harvard) löse.

Jede Aufgabe hat einen eigenen Ordner mit:
- `aufgabe.md`: der Aufgabenstellung
- der `.c`-Datei: meiner Lösung
- `versionen/`: Zwischenstände, damit man sieht, wie die Lösung entstanden ist

## Aufgaben

| Nr. | Aufgabe | Themen | Status |
|---|---|---|---|
| 01 | [Notenrechner](01-notenrechner/) | `argc`/`argv`, `do-while`, Arrays, Durchschnitt | ✅ Stufe 1 |
| 02 | [Temperatur-Tagebuch](02-temperatur-tagebuch/) | eigene Funktionen, Arrays als Parameter, Min/Max, `toupper` | ✅ alle Stufen + Bonus |
| 03 | [Suchen & Sortieren](03-suchen-sortieren/) | Linear Search, Bubble Sort, Binary Search, Big O | 🚧 in Arbeit |

## Kompilieren

```bash
gcc datei.c -o datei.exe -lcs50
```

Benötigt die [CS50-Library](https://github.com/cs50/libcs50).
